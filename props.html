How to read it. The SIG number is the model's projection for significant strikes landed if the fight reaches the scorecards — the cleanest number for an over/under, because it depends only on each fighter's own pace and how much the opponent lets them throw, not on how long the fight lasts. The bar is the middle range of likely outcomes — built so the real number should land inside it about 60% of the time; we started freezing every projection before each card in August 2026 and will publish the actual hit rate once enough fights are graded. The takedown chances already include the odds of an early finish.
Fight length is a rough baseline for now. The finish / distance split uses the average 3-round pace, the same for every fight for now — not yet tuned to these two fighters. Strike and takedown projections are fully fighter-specific.
Model output for research, not betting advice. Projections are estimates with real uncertainty — thin-tape fighters especially. No posted prop lines were used; these are the model's own numbers.
